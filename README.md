# 大型科研院所仪器设备共享平台

## 功能概述

### 核心功能模块

1. **智能预约系统**
   - 设备类型、维护周期、历史占用率智能推荐可用时段
   - 实验时长冲突自动检测与提示
   - 扫码签到，自动记录开始时间

2. **实时监控与预警**
   - 每30秒采集仪器状态数据
   - 异常状态（温度超限等）实时推送预警
   - 预警通知实验人员和仪器管理员

3. **费用与预算管理**
   - 实际时长自动计费
   - 课题组预算自动扣除
   - 预算余额低于20%自动预警

4. **维护管理系统**
   - 定期维护计划创建
   - 到期前3天自动生成维修工单
   - 智能匹配最近资质工程师
   - 维修报告上传与状态更新

5. **统计分析**
   - 课题组长：使用时长排名、费用饼图、成员优先级
   - 院领导：收费标准设置、共享率目标、月报统计
   - 每月1号自动生成对比分析报告

6. **消息通知系统**
   - 预约确认、预警、工单生成、月报等实时推送
   - 凭证下载功能

### 用户角色

- **实验人员**：预约仪器、使用签到、查看费用
- **仪器管理员**：仪器管理、维护计划、工单处理
- **课题组长**：预算管理、成员优先级、统计查看
- **院领导**：收费标准、共享率目标、全院统计
- **工程师**：工单接收、维修报告上传

## 技术架构

- **前端**：React + TypeScript + Ant Design + ECharts
- **后端**：Node.js + Express + TypeScript
- **数据库**：SQLite（开发环境）
- **实时通信**：WebSocket

## 快速开始

```bash
# 安装依赖
npm run install:all

# 启动开发环境
npm run dev
```
